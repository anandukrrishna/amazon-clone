# Amazon Clone

A responsive Amazon-inspired website built using HTML5 and CSS3 as part of my frontend development learning.

## Features

- Navigation bar with search section
- Hero section
- Product category cards
- Responsive layout for different screen sizes
- Contact and email subscription form
- Footer with multiple sections
- Hover effects and CSS transitions

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- VS Code
- Google Chrome

## Project Structure

```text
amazon-clone/
│
├── index.html
├── style.css
├── media/
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Purpose

This project was created to practise HTML structure, CSS styling, Flexbox, Grid, positioning, and responsive web design.
